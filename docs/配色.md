# 配色カラー定義（Inby）

`static/css/common.css` で実際に使われている色をまとめたもの。
新しい画面やコンポーネントを追加するときは、原則この一覧から色を選ぶ。

## ベースカラー

| 用途 | カラーコード | 使用箇所 |
| --- | --- | --- |
| ページ背景（生成り） | `#F9F7F1` | `body` の背景 |
| 本文テキスト | `#666` | `body`、`.input-title` |
| カード背景 | `#FFFFFF` | `.card-container` |
| カード枠線 | `#ddd` | `.card-container` |

## アクセントカラー

| 用途 | カラーコード | 使用箇所 |
| --- | --- | --- |
| プライマリ（サーモン） | `#EC8A76` | `.btn-complete` の背景 |
| プライマリ hover | `#d97864` | `.btn-complete:hover` |
| セカンダリ（グリーン） | `#8AB69B` | `.sidebar` の背景 |

## グレースケール

| 用途 | カラーコード | 使用箇所 |
| --- | --- | --- |
| 控えめな見出し | `#BDBDBD` | `.header-title` |
| プレースホルダー | `#999` | `input::placeholder` |
| アイコン塗り | `#888888` | `.image-section svg` |
| プレースホルダー領域の背景 | `#EEEEEE` | `.image-section` |

## 半透明・影

| 用途 | 値 | 使用箇所 |
| --- | --- | --- |
| サイドバーの影 | `rgba(0, 0, 0, 0.1)` | `box-shadow: 4px 0 15px` |
| カードの影 | `rgba(0, 0, 0, 0.05)` | `box-shadow: 0 4px 15px` |
| 入力欄 hover/focus 背景 | `rgba(0, 0, 0, 0.03)` | `input:hover`, `input:focus` |

## そのほかの共通ルール

- 角丸: ボタン・カード・画像領域は `border-radius: 10px`、入力欄の hover 背景は `4px`
- フォント: `'Helvetica Neue', Arial, 'Hiragino Kaku Gothic ProN', 'Hiragino Sans', Meiryo, sans-serif`
- ボタンのインタラクション: hover で背景を暗く、`:active` で `transform: scale(0.95)`、`transition: background-color 0.2s, transform 0.1s`

## メモ

- ホーム画面（`templates/events/home.html`）は現状 `common.css` を読み込んでおらず、上記の配色が適用されていない。
- 色は CSS 変数化されていない。今後 `:root` にカスタムプロパティとして切り出すと管理しやすくなる。
